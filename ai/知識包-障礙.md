# 知識包｜障礙（障礙版、旅行版、對手偵測）

> 來源：3-3 障礙版與備用開關、2-12 習慣不連續、3-4 拆摩擦與對手、2-8 自制力、2-11 誘惑 vs 手自己動
> 用途：種下去一週後，或使用者主動要求時。輸入是開關句＋使用者描述的打斷情況，輸出障礙版、備用開關、旅行版、對手處理建議。

## 一、三種補強，各管一種情況

| 補強 | 管什麼 | 格式 |
|---|---|---|
| 障礙版 | 開關出現了，但有東西擋住 | 如果〔障礙〕，我就〔替代動作〕 |
| 備用開關 | 開關那天根本沒出現 | 如果中午前還沒做，就在〔另一個身體事件〕時做 |
| 旅行版 | 整批情境換掉（出差、旅行、生病） | 最小一步換成帶得走的版本 |

三者都只寫「就做什麼」，不寫「就不做什麼」。

## 二、障礙版怎麼寫

1. 問使用者：過去兩週，這件事最常怎麼被打斷？只挑最常見的一到兩個。
2. 替代動作通常就是最小一步本身，或更小的版本。
3. 先想像障礙，再寫計畫（WOOP 的順序）。

常見障礙與替代範例：

| 障礙 | 替代 |
|---|---|
| 早上要出門 | 在捷運上用手機寫三行 |
| 下雨、場地有人 | 在家門口運球五分鐘 |
| 闔上筆電時已經很睏 | 先坐三個呼吸再去躺 |
| 咖啡今天沒喝 | 第一餐吃完時做 |
| 家人在客廳 | 到房間做最小一步 |

## 三、備用開關

主開關有些日子不會出現（週末不喝咖啡、今天不在家）。指定另一個穩定瞬間接手，最好也是身體事件：第一餐吃完、洗完澡、上床前。

格式固定：「如果中午前還沒〔最小一步〕，就在〔身體事件〕時做。」中午可依習慣的時段改成下午、晚上。

## 四、旅行版

先分可攜和不可攜：

| 開關綁在 | 可攜嗎 | 旅行時 |
|---|---|---|
| 身體事件（起床、刷牙、第一杯水、闔上筆電） | 可攜 | 照做，最小一步縮到更小 |
| 地點或器材（書桌、蒲團、球場、健身房） | 不可攜 | 事先決定：替代（走路、徒手、在手機上做），或明確暫停 |

- 旅行時的目標不是維持量，是讓開關和動作繼續配對。藤照長。
- 「看情況」是最差的答案，每一天都變成一次談判。要事先決定。
- **回程那一天是危險時刻**：回到原情境，好的開關回來了，舊習慣的開關也一起回來。回家前一晚就把東西擺回原位。
- 長住異地（一個月以上）當成重新安裝，第一週就寫好當地的開關句。

## 五、對手偵測

開關出現的那一刻，使用者最可能去做的另一件事，就是對手。先分類，再選招，招和類型不合就沒效。

| 類型 | 特徵 | 主要的招 |
|---|---|---|
| 誘惑 | 有「想要」的拉扯感，東西拿得開（手機、零食、電視） | 移出情境、拉開距離 |
| 手自己動 | 回過神才發現已經在做，東西拿不開（寫作用的電腦上就有瀏覽器） | 加步驟打斷、加等待時間、警覺監控 |
| 內在線索 | 觸發的是焦慮、無聊、疲累 | 觀察衝動來了又走，加替代動作。這類最難，超出 v1.5 範圍，只提醒 |
| 人或場合 | 同事的飯局、伴侶開的電視、某個朋友在場 | 改見面的情境，或跟對方一起設計；改不了就標成危險時刻 |

**問使用者的那一句**：「開關出現的那一刻，你通常手上拿著什麼、或正在做什麼？」

## 六、摩擦要多大才有感

| 等級 | 例子 | 夠不夠 |
|---|---|---|
| 提醒 | 貼紙條、桌布寫字 | 通常不夠 |
| 步驟 | 登出帳號、app 移到第三頁 | 對弱習慣有用 |
| 距離 | 手機放另一個房間、零食放櫃子最上層 | 大多數情況的起點 |
| 時間 | 開啟前要等幾秒到幾分鐘 | 對手自己動特別有用 |
| 交給別人 | 手機交給家人、密碼給朋友保管 | 最強，最難維持 |

給誘惑的建議至少要到「距離」。給手自己動的建議用「步驟」加「時間」。

**同時要拆我方的路**：從開關到最小一步，路上有幾步、幾個決定？能刪就刪，刪不掉搬到前一晚（檔案開好、球鞋放門口、決定明天做哪段）。只擋對手不拆我方，對手遠了我方還是很遠。

**阻力要在設計時刻加**（前一晚、週末），不在誘惑出現的當下。那一刻最弱。

## 七、兩個提醒，寫進 note

- 不要讓習慣只在某個人在場時才發生。夥伴是加分，不是條件。
- 阻力不要連我方一起擋（斷網之後發現寫作要查資料）。前一晚把要查的先存下來。

## 八、輸出時的判斷順序

1. 從使用者描述的打斷情況抓出最常見的一到兩個 → 各寫一條障礙版
2. 判斷主開關是不是每天都出現 → 不是就寫備用開關
3. 判斷開關綁的是身體事件還是地點器材 → 寫旅行版，不可攜的要給「替代」和「明確暫停」兩個選項
4. 如果使用者說了開關那一刻在做什麼 → 分類對手、給一條至少到「距離」等級的建議，加一條拆我方路的建議
5. 一次最多回傳：2 條障礙版、1 條備用開關、1 條旅行版、1 條對手建議。不多給。
