### A 的刻意清單（多米真機做，先寫預期）

| # | 怎麼做 | 預期 |
|---|---|---|
| A1 | 凌晨 0 點到 4 點之間按住 | 算前一天；今天頁、小工具都寫前一天的節數 |
| A2 | 按住後馬上撤銷，再按一次 | 節數只多 1；匯出的 JSON 裡有一筆帶 `deletedAt` |
| A3 | 昨天沒按，今天補記昨天，再按今天 | 今天不開花；這週的田照算兩天 |
| A4 | 請假一天，寫一個之前寫過的原因 | 請假卡出現「這個原因第 2 次了…」 |
| A5 | 開旅行中、記兩天、關掉 | 隔天出現「回家第一天…」；田「漏掉的日子」出現旅行中那一句 |
| A6 | 改一次開關句 | 田「這幾週」那一週標「改過開關」 |
| A7 | 開始放手測試、兩週後點「記不清楚」 | 第三個訊號不過；田可以再開始；放手那兩週不算漏掉，結束隔天沒有「卡住的話」 |
| A8 | 匯出備份，打開看 | `v: 2`，每筆有 `id`、`at`、`tz` |
| A9 | 用舊版（v1）的備份檔還原 | 自動先寫一份「還原前」備份；轉成 v2；田的數字跟還原前的舊版一樣 |
| A10 | 收工檢查開著，連三天不按 | 第三天起不響；記一節後隔天恢復 |

### B 的題目

- B-1 五秒測試：今天頁（記好了、還沒記兩張）、小工具兩張。問：「今天記了沒？」「這個習慣長到第幾節？」
- B-2 讀圖題：田「開始四問」（有一段沒做的週）：「哪三次差不到半格？」「中間哪裡空了？」；「這幾週記了幾天」：「哪一週記得最少？」「哪一週有請假？」。另外各給一張灰階截圖重問一次。
- B-3 讀句題：W-1、W-2、W-3、W-WE-1、W-EXP-1、P-2、D-5、「藤還在」那一頁、季稽核的結果。每一句問三題：「這句在說什麼？」「看完你會做什麼？」「讓你覺得怎樣？」記下「被唸」「冷冰冰」各出現幾次。

### C 要記的（多米自己，6 週）

每週：有沒有在記、這週的田打開了沒、看到什麼觀察、原因選了什麼（含跳過）、選了什麼做法、有沒有答應試兩週、之後兩週發生什麼。
數字從匯出的備份算：`node tools/analytics-c-report.mjs <備份檔>`（只讀檔，不上傳）。
**最容易犯的錯**：拿「選了做法前兩週 vs 後兩週」當效果。觀察只在差很大時出現，之後本來就會回來（回歸平均）。只有一個人，也不做延後顯示的抽籤。
