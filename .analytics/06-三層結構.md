## 三層規則（薯記版）

分層看「誰發起這一次看」：

| 層 | 誰發起 | 薯記的哪裡 | 上限 ⚪ |
|---|---|---|---|
| 一眼層 | 她路過 | 今天頁標題與狀態章、小工具、Siri 回的那一句 | 最多兩個數字，第二個比較小。現在每處都只有一個（M2） |
| 回顧層 | app 在固定時間點帶給她 | **「這週的田」**（新）：回顧日起三天內，記好今天之後的連結 → 開始四問 → 送出後接著出現 | 三個事實、一個觀察 |
| 細查層 | 她自己點進去 | 田 | 每一區回答一題 |
| 操作畫面上的一行 | 跟著操作出現 | 請假卡、放手結束頁、今天頁的提示 | 一行 |

## 每個畫面的三種狀態

| 畫面 | 資料不夠 | 平常 | 回來（停頓之後） |
|---|---|---|---|
| 今天頁標題 | 還沒記過第一節：只寫日期，不寫「第 0 節」 | 日期 · 第 N 節 | 同平常 |
| 今天頁，停了一陣子（2026-11-25） | — | — | 按住之前沒有問題；記好之後出一行「上次卡在哪？」 |
| 田「都在什麼時候做？」（2026-11-25） | 不出 | 多半{時段} {n} 點多 | 同平常 |
| 小工具 | 一節都沒有：「今天還沒記」 | 「今天記了 · 第 N 節」「今天還沒記 · 已長 N 節」 | 同平常 |
| 這週的田 W-1 | 種下未滿一週：「種下去第 d 天，記了 n 天」；完整週不到 2 週：寫還差幾週 | 這週天數＋前幾週的範圍 | 「這週接上了，記了 n 天」，不比較；還在停的期間打開：「這週沒有紀錄。」 |
| 這週的田 W-2 | 做了不到 3 次：寫做到第 3 次就看得出 | 最近三次的方向 | 「線接著畫，這次先不看方向」 |
| 這週的田 W-3 | 開始四問不到 6 次：寫現在幾次 | 三個訊號過了幾個 | 同平常 |
| 這週的田 觀察 | 不出 | 過門檻、沒在冷卻才出，最多一個 | 不出（試兩週的結果也延到下週） |
| 田「長好了嗎」 | S1 寫現在幾次 | 三列 | 同平常 |
| 田「開始四問」 | 一次都沒有：空狀態（已有） | 線 | 線在停頓那段斷開 |
| 田「這幾週」 | 未滿一週：寫滿一週就列 | 每週一列 | 停頓的週寫「沒有紀錄」，不畫 0 |
| 田「漏掉的日子」 | 寫還要大約幾週 | 原始天數＋「先不下結論」或「差得比平常的起伏大」 | 停頓的日子不算進來，寫一句 |

## 層間入口

- 小工具點了 → 打開今天頁（要記下一節），**不是**田。
- 今天頁記好之後「今天週回顧 · 開始四問」→ 回顧卡：開始四問 → 這週的田。
- 田「做這週的開始四問」→ 同一張回顧卡。田「這週的田」那一列 → 回顧卡直接顯示這週的田（不必再做四問）。
- 這週的田「去田看看」→ 關卡片、切到田。
- 觀察的做法 → 設定頁那一格（開關、最小一步、不順的時候、旅行版）或「讓開始更容易」那張卡。「不順的時候」另有 AI 助手按鈕（免費，任務 2）。
- 走平在低處那一句 → 「看開關句」按鈕到設定頁（P1-11）。

## 週回顧觀察的挑選順序（同一週最多一個）

1. 她自己答應的試兩週，到期了的結果
2. 同一個請假原因（她自己寫的原因，直接接到下一次請假的決定）
3. 平日／週末
4. 旅行中／在家

跳過的條件：放手測試中、回來週、同一種觀察 28 天內出過、同一種觀察的試兩週正在進行。原因連續 3 次跳過或「不確定」之後，只說現象。

## 不放清單

- 田最上面的統計格（根、回來、漏掉、本月請假）：拿掉（審查 P1-9）
- 漏掉總天數、完成率、連續天數：任何一層都不放
- 一眼層的比較句（「比平常少」）：不放；比較只在回顧層
- 一眼層的「第 0 節」「今天 0 個」：不放
- 兩個以上的觀察：不放
- 開始四問的分數：不放（只畫線、只說方向）
- 跟別人比：不放
- 細查層的推播：沒有
