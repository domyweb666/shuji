# 薯記原生版：該補、該砍、別碰

這份是把原型（`index.html`）整個讀完、移植成 SwiftUI 之後的判斷。先講結論：原型的產品判斷大多站得住，一次一個、不數連續、回來開花、放手測試，這些都別動。原生版真正要補的是「資料不會丟」和「存了卻沒露面的欄位」，要砍的是幾個住錯地方的設定。

## 移植時已經做掉的

| 項目 | 做了什麼 | 為什麼 |
|---|---|---|
| 收工檢查 | 通知真的能開。一天最多一則，記了就不響，放手測試中不響，預設關 | 原型就標「原生版才有」。一則、不催、可關，才不會變成另一個催人的 app |
| 測試區 | 只留在 Debug 建置 | 原型標「正式版沒有這一區」 |
| 全部清除 | 只留在 Debug 測試區，正式版沒有 | 照原型；要重來就刪掉 app 重裝（2026-11-07 拍板） |
| 放手測試算錯 | 那兩週不算漏掉；測試剛結束不會跳「停了一陣子」 | 原型跑完放手測試，主畫面會說你停了一陣子、田裡多 14 天漏掉。剛過關的人看到這個會很悶 |
| 備份格式 | JSON 跟原型一字不差 | 原型用戶貼一段文字就能搬過來 |
| 觸覺、聲音 | Taptic 三種；音效合成；跟靜音鍵走 | 網頁只能用 Safari 那一種震動 |

## 第一批（2026-11-07 已做）

| 項目 | 做了什麼 | 為什麼 |
|---|---|---|
| 為了什麼 | 「停了一陣子」那頁，開關句下面多一張卡「你說這是為了：⋯」 | 存了沒人看得到，而那頁正是最需要它的時候 |
| 不順的時候 | 連漏兩天的提示下面，把備案那句放出來 | 漏掉的原因常常就是主開關那天沒出現 |
| 週回顧連結 | 回顧日當天到之後三天，記完那一節都看得到「開始四問」連結 | 原型只有回顧日當天看得到，漏掉就得自己去田裡找 |
| 挖地瓜自動備份 | 資料歸零前先寫一份 JSON 到 Documents，檔案 app 看得到 | 那是唯一一次把 logs 整個清掉的時刻 |
| 四點換日說明 | 設定頁「節奏」加一行 | 對夜貓子很重要，但 app 裡沒講 |
| 聲音開關 | 拿掉。音效跟手機側邊的靜音鍵走，震動留 | 兩個開關管同一件事，多一個決定 |
| 障礙版＋備用開關 | 合成一個「不順的時候」欄位。舊資料的障礙版自動併進去，兩個 key 都留著，原型還讀得到 | 對使用者是同一題：今天不順做什麼 |
| 讓開始更容易 | 從設定頁拿掉，變成「卡住了」那頁第三列點開的卡 | 三條靜態文字不是設定，卡住的時候才用得到 |

## 第二批（2026-11-07 已做）

| 項目 | 做了什麼 | 為什麼 |
|---|---|---|
| 開始四問預設 | 七點量表沒有預設值，四題都點過「記下這週」才亮 | 預設 4 很多人直接送，曲線永遠走平 |
| 放手測試提早結束 | 拿掉。兩週就是兩週 | 提早結束後「做了幾天」沒有基準，有沒有變少判斷不準 |
| 記一節捷徑 | App Intent「記一節」，接 Siri、捷徑 app、iPhone 15 Pro 以後的動作按鈕。沒種、放手測試中、今天記過或請假都會用一句話回你，不會重複記 | 動作按鈕要按住才觸發，手感跟 app 裡的按住接近；做起來小 |

## 之後再補的（照順序）

### 1. 資料同步，不只是備份

原型最大的風險是資料只在瀏覽器裡，Safari 七天沒開就可能清掉。原生版存檔案、跟 iCloud 備份走，已經好很多，但「換手機還原整機」和「兩台裝置同步」是兩回事。資料量很小（一年的紀錄不到 10 KB），用 `NSUbiquitousKeyValueStore` 就夠，不用上 CloudKit。要 iCloud 容器，所以得有付費開發者帳號，而且要走 TestFlight 那條簽章路線才裝得進手機。

### 2. 小工具（Widget）

鎖定畫面或桌面放一個：開關句＋今天記了沒。不放按鈕，記一節還是得進 app 按住。原型說「開關要在生活裡，不在手機裡」，小工具是被動看到，跟這句不衝突；加按鈕就衝突了，點一下跟按住一秒半是兩種動作。（2026-11-07 使用者點頭，下一個 PR 做。）

## 別碰的

這些是原型刻意不做的，原生版也不要因為「別的習慣 app 都有」就補：

- 同時種兩個以上的習慣。
- 連續天數、火焰、最高紀錄。
- 分享到社群、排行榜、好友。
- 每天推一句激勵語。
- 遊戲化獎勵（點數、徽章）。藤和花已經是回饋了，再加就變另一個 app。

## 跟原型不同的決定（2026-11-07 已拍板）

- 「全部清除」改回原型：正式版不給清，只留在 Debug 測試區。
- 收工檢查的文案維持：「今天還沒記一節。開關有出現嗎？做完最小一步，回來按住一下。」
- 放手測試的 14 天從「漏掉」裡排除，維持。
- 聲音開關拿掉，維持；聲音跟手機側邊靜音鍵走。
