# 薯記原生版：該補、該砍、別碰

這份是把原型（`index.html`）整個讀完、移植成 SwiftUI 之後的判斷。先講結論：原型的產品判斷大多站得住，一次一個、不數連續、回來開花、放手測試，這些都別動。原生版真正要補的是「資料不會丟」和「存了卻沒露面的欄位」，要砍的是幾個住錯地方的設定。

## 這次移植已經做掉的

| 項目 | 做了什麼 | 為什麼 |
|---|---|---|
| 收工檢查 | 通知真的能開。一天最多一則，記了就不響，放手測試中不響，預設關 | 原型就標「原生版才有」。一則、不催、可關，才不會變成另一個催人的 app |
| 測試區 | 只留在 Debug 建置 | 原型標「正式版沒有這一區」 |
| 全部清除 | 搬到「資料」底下，按了再問一次 | 正式版還是要有辦法重來，但不能一不小心按到 |
| 放手測試算錯 | 那兩週不算漏掉；測試剛結束不會跳「停了一陣子」 | 原型跑完放手測試，主畫面會說你停了一陣子、田裡多 14 天漏掉。剛過關的人看到這個會很悶 |
| 卡住第三列捲錯 | 「旁邊有更近的東西搶走了嗎」改捲到「讓開始更容易」 | 原型捲到「什麼時候不適合」那顆按鈕，是 id 接錯 |
| 備份格式 | JSON 跟原型一字不差 | 原型用戶貼一段文字就能搬過來 |
| 觸覺、聲音 | Taptic 三種；音效合成；跟靜音鍵走 | 網頁只能用 Safari 那一種震動 |

## 建議補的（照順序）

### 1. 資料同步，不只是備份

原型最大的風險是資料只在瀏覽器裡，Safari 七天沒開就可能清掉。原生版存檔案、跟 iCloud 備份走，已經好很多，但「換手機還原整機」和「兩台裝置同步」是兩回事。資料量很小（一年的紀錄不到 10 KB），用 `NSUbiquitousKeyValueStore` 就夠，不用上 CloudKit。要 iCloud 容器，所以得有付費開發者帳號，上架本來就要。

### 2. 「為了什麼」和「備用開關」要有露面的地方

設定頁有四個欄位存了之後整個 app 沒有任何地方會再顯示：為了什麼、障礙版、備用開關、旅行版最小一步（旅行版有用到）。存了不給看，等於沒存。建議：

- 「停了一陣子」那頁，開關句下面放一行「你說這是為了：⋯」。這是最需要它的時候。
- 連漏兩天的提示下面，放備用開關那句。使用者漏掉的原因常常就是主開關那天沒出現。

### 3. 小工具（Widget）

鎖定畫面或桌面放一個：開關句＋今天記了沒。不放按鈕，記一節還是得進 app 按住。原型說「開關要在生活裡，不在手機裡」，小工具是被動看到，跟這句不衝突；加按鈕就衝突了，點一下跟按住一秒半是兩種動作。

### 4. 捷徑與動作按鈕

做一個「記一節」的 App Intent，接 Siri、捷徑、iPhone 15 Pro 以後的動作按鈕。動作按鈕要按住才觸發，手感跟 app 裡的按住很接近。優先度低，但做起來小。

### 5. 週回顧沒做的話，隔天還看得到

現在「今天週回顧 · 開始四問」只在回顧日當天、而且已經記了那一節才出現。回顧日漏掉，就得自己去田裡找。建議回顧日之後三天內沒做四問，主畫面都留那個連結。

### 6. 挖地瓜時自動存一份備份

挖地瓜是資料一次清空的時刻（logs、weekly 全歸零）。在這一刻自動寫一份 JSON 到 app 的 Documents，開 `UIFileSharingEnabled` 讓檔案 app 看得到。不用使用者記得匯出。

### 7. 四點換日要講

凌晨四點前算前一天，這個規則對夜貓子很重要，但 app 裡沒有任何地方說。設定頁「節奏」那區加一行說明就好，不用做成可調的。

## 建議砍的或改的

### 1. 「讓開始更容易」不該住在設定頁

三條靜態文字，不是設定，改不了也關不掉。它真正派得上用場的時機是「卡住」那條路徑。建議從設定頁拿掉，做成「卡住了」那頁的一張卡。這次移植先讓它留在原位並給了錨點，沒搬。

### 2. 「障礙版」和「備用開關」合併成一個

「如果〔障礙〕，就〔替代〕」和「主開關沒出現的日子怎麼辦」，對使用者來說是同一題：今天不順的時候做什麼。兩個欄位疊在一起，大部分人會空著。合成一個「不順的時候」欄位，placeholder 給一個例子。

### 3. 「聲音」開關可以拿掉

原生版的音效跟靜音鍵走，使用者本來就有一個開關在手機側邊。app 裡再放一個，多一個決定。我覺得拿掉，震動留著。

### 4. 開始四問預設 4 分

七點量表預設停在正中間，很多人會直接按「記下這週」，曲線永遠走平。建議預設不選，四題都點過才能送出。

### 5. 放手測試的「提早結束」

提早結束後，結算畫面還是問「這兩週做了幾天」，上限 14 天，但實際只過了幾天，數字沒有基準，「有沒有變少」的判斷就不準。兩個選法：問句改成「這 N 天」、上限改 N、跟前 N 天比；或者乾脆不給提早結束。我覺得後者，兩週就是兩週。

## 別碰的

這些是原型刻意不做的，原生版也不要因為「別的習慣 app 都有」就補：

- 同時種兩個以上的習慣。
- 連續天數、火焰、最高紀錄。
- 分享到社群、排行榜、好友。
- 每天推一句激勵語。
- 遊戲化獎勵（點數、徽章）。藤和花已經是回饋了，再加就變另一個 app。

## 跟原型不同、需要你確認的決定

- 「全部清除」放在正式版的「資料」區。原型的意思可能是正式版完全不給清。
- 收工檢查的文案是我寫的：「今天還沒記一節。開關有出現嗎？做完最小一步，回來按住一下。」原型沒有這句，可以改。
- 放手測試的 14 天從「漏掉」裡排除，這改變了田裡的數字。原型沒這樣做。
