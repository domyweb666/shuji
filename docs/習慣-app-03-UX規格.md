## 一、頁面結構：三頁橫向，主畫面在中間

| 手勢 | 進到哪 | 放什麼 |
|---|---|---|
| — | **主畫面** | 開關句、按住記一節、地瓜藤 |
| 手指往右滑 | **田**（其他功能頁） | 這個習慣的數字、開始四問曲線、長好了嗎、竹籃、排隊 |
| 手指往左滑 | **設定** | 開關句、旅行中、請假次數、週回顧日、聲音、提醒、備份、不適合清單 |

- 頂端三個小圓點標示位置，點圓點也能切換
- **按住進行中鎖住滑動**，圓點淡出
- 首次設定期間不能滑（只有一件事要做）；首次設定拆兩步，一個畫面只問一個問題（2026-11-06 改）
- 桌面寬度時主畫面限制在 560px 置中

## 三、核心迴圈

```
生活裡的開關出現（起床喝完水）
  → 做最小一步（打開檔案寫一句）
    → 拿起手機：鎖定畫面控制項按一下（原生）／打開 app 按住（原型）
      → 完成瞬間：藤長一節、根紮下去、回來就開花
        → 主畫面安靜下來，看得到今天這一節
          → 明天的理由：藤的尾端在等下一節；週回顧日有曲線可看
```

迴圈裡**沒有**任何一步要做決定。

## 四、完成瞬間規格

| 層 | 規格 |
|---|---|
| 按住 | 1.5 秒。按下時外圈開始填色；中途放開就退回，不算 |
| 藤 | 尾端往前長一節（0.6 秒，彈簧緩出）；新節點的葉子從 0 長到 1，帶一點過衝 |
| 根 | 葉子長好之後，一條根從節點往土裡畫下去（0.8 秒） |
| 花 | 回來的那一節，葉子之後 0.2 秒開一朵紫色地瓜花（彈出＋輕微旋轉） |
| 土 | 根紮下去時，土面跳起 6–8 顆小土粒 |
| 鏡頭 | 藤超過畫面時，整條往左平移，讓新節點停在右側三分之二處 |
| 觸感（原生） | 按下：light impact；按住期間每 0.3 秒 selection；完成：success notification；開花再一下 soft impact |
| 觸感（原型） | iOS 18 以上 Safari 用 switch 輸入框的系統觸感，只在按下與完成各一下 |
| 聲音 | 預設開。完成時一聲短促、偏低的木頭撥音；開花多一聲高一點的。設定可關 |
| 文字 | 完成語庫 22 則、回來語庫 10 則，同一天固定一則，避免連續兩天重複 |
| 減少動態效果 | 系統開啟時：不平移、不彈跳，節點直接出現，只保留淡入 |

平常畫面保持安靜：葉子會隨手機傾斜慢慢擺，點一下會晃，沒有其他動畫。

## 五、田（其他功能頁）

由上到下：

1. **大標題「田」**＋次要灰一行：開關句縮寫
2. **白卡片：這一個**
   - 根（做到的次數）　N
   - 回來　a 次／漏掉　b 次
   - 本月請假　n／上限
   - 種下去那天　日期
3. **白卡片：開始四問**——折線圖（1–7 分），最近 8 週；底下「做這週的開始四問 ›」
4. **白卡片：長好了嗎**——三列，每列一個訊號，打勾或空圈；兩個通過時出現「挖地瓜」按鈕
5. **竹籃**——畢業的地瓜，一顆一列：名字、根數、回來次數、種了多久；點開看當初的開關句
6. **排隊**——之後想裝的習慣，一行一個，可新增、刪除

不做：月曆熱力圖、連續天數、完成率百分比。

## 六、設定頁

| 分區 | 列 |
|---|---|
| 開關句 | 如果（瞬間）／我就（最小一步）／障礙版：如果〔障礙〕，就〔替代〕／備用開關 |
| 這件事為了什麼 | 一句話，選填 |
| 旅行中 | 開關＋旅行版最小一步 |
| 節奏 | 每月請假次數（0／1／2／3）／週回顧日 |
| 讓開始更容易 | 三行提示，不是設定 |
| 聲音與提醒 | 聲音開關／收工檢查（原生版才有，原型顯示灰色） |
| 資料 | 匯出備份／從備份還原 |
| 關於 | 什麼時候不適合用這個 app |
| 測試區（只在原型） | 往後一天／載入示範資料／清除全部 |

## 七、介面風格

照 domi-learn-app 3-4 蘋果原生規格，不另找視覺方向。這個 app 的個別設定：

- **主色：系統紫 #AF52DE**（深色模式 #BF5AF2），全 app 只有它是彩色的
- 唯一例外：地瓜藤插圖區（葉子綠、土棕、花紫），它是插圖，不是介面
- 土的區塊是插圖：淺色模式暖棕，深色模式更暗的棕，上緣不規則

## 八、插圖畫風與生圖提示詞

系列畫風：軟萌黏土公仔、作物本身長臉、霧面細顆粒、圓潤矮胖、豆豆眼、粉色腮紅、綠葉、左上方柔光。

**角色：地瓜**——紅紫色外皮、表面有幾條淺淺的紋路和小鬚根，頭頂兩三片心形地瓜葉。

### 生圖順序

**1. 表情設定圖（定錨，先生這張）**

> 軟萌黏土公仔風格的角色表情設定圖，角色是一顆長了臉的地瓜：紅紫色外皮、霧面細顆粒黏土質感、圓潤矮胖、表面有幾條淺淺的橫紋和兩三根細小鬚根，頭頂長著兩片翠綠色心形地瓜葉。豆豆眼、粉色腮紅、小小的嘴。同一張圖裡排成一列五個表情：平靜、開心（眼睛彎彎）、睡著（閉眼、頭上一個小小的 z）、疑惑（歪頭、一片葉子垂下）、驕傲（抬頭、葉子翹起）。每個之間留足夠白色空隙方便裁切。白色背景，左上方柔和打光，柔和陰影，無文字。

**2. 之後每一張**都上傳第 1 張，開頭寫：「參考上傳的圖片，維持完全一樣的畫風、質感、光線和配色。」

| 資產 | 提示詞重點 |
|---|---|
| 空狀態 | 地瓜角色坐在一個空的小竹籃旁邊，旁邊一小堆土，土上冒出一根小芽。透明背景 |
| 睡覺 | 地瓜角色睡在一片大地瓜葉上，閉眼、頭上一個 z。透明背景 |
| 收集物：一節 | 一段地瓜藤，一個節點上長一片心形葉，節點下方幾條細根。只有藤和葉，沒有角色。透明背景 |
| 收集物：花 | 一朵淡紫色喇叭形地瓜花，花心較深的紫，正面略側。透明背景 |
| 收集物：挖出來的地瓜 | 一顆剛挖出來的地瓜，沾一點土，連著一小段藤和兩片葉（不長臉）。透明背景 |
| 竹籃 | 一個裝了四顆地瓜的小竹籃，正面略俯視。透明背景 |
| 場景：田 | 橫向的一塊田，上半是淺色天空留白，下半是柔軟的棕色土，土面有一條地瓜藤往右延伸，節點下有根伸進土裡。黏土質感 |

**處理**：裁透明邊 → 縮到顯示尺寸 2 倍 → WebP 品質 85，總量 500 KB 內。

## 九、原生功能選擇（MVP 選兩個）

| 原生能力 | 選不選 | 理由 |
|---|---|---|
| **鎖定畫面／控制中心控制項（iOS 18 Controls）** | ✅ 第一個 | 解決階段一最大的風險：記這一筆不用解鎖、不用打開 app，就不會順手滑出去 |
| **Haptics** | ✅ 第二個 | 完成瞬間 |
| 主畫面小工具 | 次選 | 顯示今天這一節有沒有記；v1.1 |
| 即時動態／動態島 | 不選 | 動作沒有時間長度 |
| Apple Watch | v2 | 適合，但多一套介面 |
| 推播 | 預設關 | 機制表二、三 |
| HealthKit、螢幕使用時間 | 不選 | 不綁特定習慣類型 |

## 十、手感原型說明

- 單檔 `習慣-app-原型.html`，資料存在瀏覽器裡，設定頁可以匯出備份
- 只做核心迴圈＋田＋設定；觸感用 iOS 18 Safari 的系統開關觸感代替，鎖定畫面控制項原型做不到
- 測試區可以「往後一天」，用來看漏掉、回來開花、週回顧、14 天回來這些狀態
- **原型的目的只有一個：多米連用 7 天，看自己會不會每天按**
