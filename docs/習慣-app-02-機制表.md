# 《習慣》APP 化｜階段二：機制表

> 2026-11-06｜domi-learn-app 階段二｜接 習慣-app-01-核心動作.md
> 暫定名：**薯記**｜核心動作：開關出現 → 做最小一步 → 按住記一節｜收集物：地瓜藤

---

## 一、設計原則（第一部公理 → 這個 app 不准做什麼）

| # | 原則 | 來自 | 全 app 不准 |
|---|---|---|---|
| 1 | **開關在生活裡，不在手機裡** | 公理二（聯結律）；2-2 提醒不等於開關 | 不准用推播當開關；不准讓「打開 app」變成習慣的觸發點。app 只在做完之後出現 |
| 2 | **每天不准有決定** | 公理一（快取）；推論 7 每多一步就多一個決定點 | 每天的操作只有「按住一下」。做多少、做哪個、要不要加量，全部在設定時刻決定，不在每天的畫面上問 |
| 3 | **回饋要立刻，而且綁在最小一步** | 公理三（效果律）；3-5 驗收第 1、2 題 | 不准把回饋綁在量、時長、成果上；不准另立點數、金幣、經驗值 |
| 4 | **只能蓋過，不能刪除** | 公理二推論 9；2-11 | 不准歸零、不准讓已長的藤枯掉、不准出現「重新開始第 1 天」 |

## 二、書 → app 轉換表

### 2-1 機制（只轉跟核心動作直接相關的章）

| 機制 | 怎麼運作 | 引用章 | 證據 |
|---|---|---|---|
| **一個開關句** | 首次設定只問兩格：「如果〔一個瞬間〕，我就〔最小一步〕」。這一句永遠顯示在主畫面上 | 2-6、3-3 | 🟢（效果下修） |
| **「就」後面不准有「不」** | 最小一步出現「不、別、戒、少」時，輸入框下方提示換成做得出來的動作，按鈕不給按 | 2-6 否定句反彈、3-1 加法篩子 | 🟢 |
| **最小一步要兩分鐘內** | 輸入超過約 20 字時提示「這比較像平常想做到的量，最小一步要小到最糟的一天也做得到」；不阻擋 | 3-2 驗收第 1 題 | ⚪ 兩分鐘是經驗值 |
| **按住記一節** | 做完最小一步之後按住 1.5 秒，藤長一節、紮一條根。只做最小一步也算一節 | 3-5 停兩秒、3-6 地板就打勾 | 🟢 記錄行為／⚪ 停兩秒 |
| **只記行為，不記量** | 沒有字數、分鐘數、心情欄 | 3-6 Harkin 2016：記錄行為改變行為 | 🟢 |
| **一次只裝一個** | 同一時間只有一個習慣在安裝中；其他想養的放進「排隊」 | 2-6 錯開啟用、3-1 步驟 4、3-7 | 🟡 |
| **回來開花** | 漏了至少一天之後回來記的那一節，開一朵紫色地瓜花。固定規則，每次回來都開 | 2-4、3-5：Milkman 2021 獎勵回來最有效 | 🟢 |
| **請假（緊急額度）** | 每月預設 2 次，可設 0–3。用的時候寫一行原因；那天畫一個小圈，不算漏，隔天不算「回來」 | 3-2 Sharif & Shu | 🟡 |
| **補記昨天** | 只能補記「昨天做了但忘了按」，不能補記更早；這是補紀錄，不是補做 | 3-6 不補做（補紀錄不違反） | ⚪ |
| **旅行中** | 一顆開關：主畫面的最小一步換成旅行版；藤照長 | 2-12 可攜／不可攜、3-2 地板就是旅行版 | 🟢 換情境會斷／🟡 |
| **開始四問** | 每週一次，四題 1–7 分，只問「開始」，畫成曲線 | 2-3、2-9、3-6 步驟 3 | 🟢 量表可靠 |
| **長好了嗎（畢業）** | 三個訊號至少兩個通過：①最近三週開始四問相差 ≤0.5（至少 6 週資料）②最近的壓力週還照做、沒怎麼談判 ③放手測試兩週不記，回想做的天數沒有明顯變少 | 3-7 | ⚪ 三訊號是本書綜合 |
| **挖地瓜** | 判定通過 → 挖出一顆地瓜放進竹籃，刻上名字、根數、回來次數；主畫面回到「種下一個」，從排隊拿 | 3-7 放手清單 | ⚪ |
| **放手後環境留著** | 畢業時提醒：開關、手機放哪、東西擺哪，都留著；只拆記錄 | 3-7 步驟 5「留」 | ⚪ |

### 2-2 失效邊界 → 防呆與不推條件（if-then）

| 如果 | 就 | 引用章 |
|---|---|---|
| 漏了 1 天 | 什麼都不說。下次記的時候開花、顯示回來語 | 2-3 漏一次只是停格 |
| 連漏 2 天 | 主畫面開關句下方出現一行小字：「卡住的話，看看是不是開關沒出現，或最小一步太大。」可以點進去改。不推播 | 3-6 連漏兩次是警訊、第四部歸因 1–4 |
| 同一個原因請假第二次 | 請假時看到上次寫的原因，下方一行：「這個原因第二次了，可能是開關要換。」 | 3-6 同一原因第二次＝設計問題 |
| 超過 14 天沒記 | 打開時：「藤還在，根都還在。」三個問題（開關有出現嗎／最小一步太大嗎／有更近的對手嗎），各自連到設定改；改完就從下一節接上，不重算 | 3-6 步驟 6 重新安裝、2-11 |
| 旅行中結束（關掉開關） | 隔天主畫面一行：「回家第一天，東西擺回原位了嗎？」只出現一次 | 2-11 ABA、2-12 回程是危險時刻 |
| 開始四問曲線走平在 3 分以下 | 「長好了嗎」卡片不說失敗，只說：「有些事會一直需要你出力，這也沒關係。要不要看看開關和最小一步？」 | 3-7 步驟 4 最後一列 |
| 想同時開第二個 | 擋下，放進排隊，說明一句：「一次裝一個，兩個都還在長的時候會搶同一份注意力。」 | 2-6、3-7 |

### 2-3 第三部流程層 → onboarding 與使用節奏

| 書的步驟 | app 怎麼放 |
|---|---|
| 3-1 從目標翻成行為 | **不放進首次設定**（要判斷，太慢）。設定頁可選填「這件事為了什麼」一句，季稽核時用 |
| 3-2 縮到最小 | 首次設定第 1 格，附 5 個範例可點選 |
| 3-3 挑錨點寫 if-then | 首次設定第 2 格，附 6 個常見瞬間可點選（起床喝完水、刷完牙、咖啡端上桌、坐到書桌、闔上筆電、上床前）。障礙版、備用開關放設定頁，可選 |
| 3-4 拆摩擦 | v1 不做互動流程；設定頁「讓開始更容易」放三行提示（前一晚準備好、手機放遠、把決定提前做） |
| 3-5 回饋 | 完成瞬間本身 |
| 3-6 重複期 | 每天按一下＋每週開始四問 |
| 3-7 判定與放手 | 「長好了嗎」卡片＋放手測試＋挖地瓜 |
| 3-8 季稽核 | v1 不做；畢業的地瓜在竹籃裡可以點開看當初的開關句 |
| 3-9 拆舊習慣 | 不做，是第二個 app 候選 |

**首次打開到第一次記一節：目標 ≤60 秒。** 兩格輸入、點選範例就能填完、按「種下去」、立刻可以按第一節（第一次允許當下就記，因為多數人設定時剛好就能做一次最小一步）。

### 2-4 第四部易混淆 → 介面用詞

| 用這個 | 不用這個 | 理由 |
|---|---|---|
| 開關 | 提醒、觸發點 | 2-2：提醒要你決定，開關推你去做 |
| 最小一步 | 目標、任務 | 3-2：地板是習慣的、量是目標的 |
| 記一節 | 完成、打卡 | 「完成」暗示要做完整件事（2-9） |
| 漏掉 | 失敗、斷了、中斷 | 2-3：漏一次是停格 |
| 回來 | 恢復連續、重新開始 | 3-5 |
| 長好了 | 養成了、成功 | 3-7：自動化是程度，不是終點 |
| 請假 | 跳過、作弊 | 3-2：緊急額度有代價、有上限 |
| 開始四問 | 習慣分數、自律指數 | 2-9：只量開始 |

### 2-5 第四部偽科學旗 → 禁用清單

介面、完成語、推播、App Store 描述、截圖文字，以下全部不准出現：

| 不准寫 | 原因 | 章 |
|---|---|---|
| 21 天、66 天、X 天養成習慣 | 🔴 | 2-3 |
| 連續 X 天、不要斷、別破壞紀錄、streak | 🔴 斷掉會降低投入 | 2-3、3-5 |
| 前功盡棄、白費、重新開始 | 🔴 | 2-3、2-12 |
| 意志力、自律、毅力、靠決心 | 🔴 油箱模型被推翻 | 2-8 |
| 我是＿＿的人（身分宣告、名詞措辭） | 🔴 名詞效應複製失敗 | 2-10 |
| 每天進步 1% | ⚪ 比喻，不寫成承諾 | 第四部 |
| 戒掉、刪除壞習慣 | 🔴 只能蓋過 | 2-11 |
| 多巴胺、大腦獎勵你 | 🟡 多巴胺主要編碼預測誤差 | 2-4 |
| 新年新開始、星期一重新出發 | 🔴 時間地標只改動機 | 2-12 |
| 科學證實會讓你養成習慣、保證 | 證據等級撐不住效果宣稱 | 2-6、3-1 |

App Store 描述只能寫成「幫你〔做某件事〕」，不能寫「會讓你〔得到某個結果〕」。

### 2-6 第四部常見死法與歸因 → 回流設計

| 回來的情況 | app 怎麼接 |
|---|---|
| 漏了 1 天 | 開花＋回來語，不提漏掉 |
| 漏了 2–13 天 | 開花＋回來語；月曆上漏掉的格子是空白，不上紅色 |
| 漏了 14 天以上 | 重新安裝流程（見 2-2 最後幾列），不重算、不清空 |
| 刪掉 app 再裝 | 首次畫面有「從備份還原」 |

### 2-7 第五部 ❓ → 不做或做成設定

| 還沒定論的事 | app 的處理 |
|---|---|
| 從極小開始 vs 一開始就足量（❓） | 不替使用者選邊：最小一步由使用者寫，只在超過約 20 字時提示，不阻擋 |
| 自動化量表靠自我回報（❓） | 不顯示「分數」或「等級」，只畫曲線；畢業要三個訊號裡兩個，不靠單一分數 |
| 早上做比較快（🟡 一篇小研究） | 範例瞬間早晚都有，不推薦時段 |
| 一次只開一個（🟡 證據來自戒除研究） | 這是產品立場，照做；但在說明裡老實寫「這是本書的判斷」 |

### 2-8 第五部出師檢核 → 進階層

不放首頁。v1 只有：開始四問曲線、長好了嗎、竹籃。季稽核、加量、換情境都留到 v2。

試用回饋寫進 `習慣-app-lessons.md`。特別要觀察的：有沒有人為了開花故意漏一天（見三、倫理護欄）。

## 三、倫理護欄

| 機制 | 這個 app 的決定 | 書支不支持 |
|---|---|---|
| 連續天數 | **不做，也不顯示**。月曆只畫做了的格子，空格沒有顏色 | 書反對：3-5 斷掉的連續紀錄降低投入；Streaks 評論最大宗抱怨 |
| 隨機獎勵 | **不做**。開花是固定規則（每次回來都開） | 書反對拿不確定獎賞對使用者用：2-4、3-5 倫理提醒 |
| 稀有收集物 | **不做**（不做「第 10 節金色」）。 | 3-5：獎賞綁在地板；固定里程碑會讓人把「節數」當目標，接近 2-3 的天數迷思 |
| 推播 | **預設關閉**。可開一則「收工檢查」，使用者自訂時間，文案只問「今天的最小一步做了嗎？」 | 2-2：提醒不是開關，推播當開關會讓習慣綁在通知上 |
| 罪惡感文案 | **不做** | 3-6 戒斷違反效應 |
| 外在獎勵 | 地瓜藤是行為的證據，不是報酬；沒有商店、沒有點數 | 2-4：外在獎賞撤掉大多留不住；過度辯護效應 |
| 社交比較、排行榜 | **不做**；也不做「公開宣告目標」 | 2-13：宣告身分可能提早滿足 |
| 回來開花會不會被刷 | 可能有人故意漏一天換花。花不能換任何東西，影響有限；竹籃記錄「回來次數／漏掉次數」並列，故意漏會讓漏掉次數一起變大。試用期觀察 | ⚪ |
| 一次只裝一個 | 硬限制（2026-11-06 多米選 A：維持一個，不做「最多兩個」的軟限制）。和 Atoms 被抱怨「只能三個」是同一類風險；用更顯眼的排隊補：種新習慣時排隊項目排第一、田的「長好了嗎」寫出下一個是誰 | 2-6、3-7 |
| 不適合的人 | 設定頁「什麼時候不適合用這個 app」：成癮、強迫、拔毛摳皮、飲食相關目標、持續兩週以上提不起勁；附戒菸專線 0800-63-63-63、安心專線 1925 | 第五部一 A |
| 飲食相關目標 | 最小一步或開關句出現「減重、卡路里、少吃、斷食、體重」時，下方一行溫和提醒並連到「不適合」頁。不阻擋 | 第五部一 A：工具可能被拿來強化限制 |

## 四、明確不做

**從階段一砍掉的動作**
- 拆舊習慣（抓到一次、換一個出口、危險時刻表）→ 第二個 app
- 一步檢查、摩擦表的互動流程（只留三行提示）
- 季稽核、加量、換情境（v2）

**轉換表沒轉的**
- 3-1 行為卡完整流程（方向、五篩子）
- 第四部症狀速查與十層歸因的完整版（只留連漏兩次、14 天回來兩個入口）
- 附錄的學派、術語、閱讀版內容（app 不是書的搬家）

**倫理護欄擋下的**
- 連續天數、streak、斷鏈
- 隨機獎勵、寶箱、稀有收集物
- 點數、金幣、商店
- 排行榜、好友、公開分享進度
- 罪惡感推播、預設開啟的推播

**刻意不做的常見功能**
- 同時追蹤多個習慣
- 記錄時長、字數、次數、心情
- 每節附的文字筆記、感悟、訓練紀錄（2026-11-06 多米確認不加：記結果會把注意力從開始拉到做得夠不夠，地板日也會顯得不夠；重訓的組數重量屬於執行層，交給專門的訓練紀錄工具）
- 習慣範本庫、AI 建議習慣
- 每週幾天、只在平日這類排程（v1 只做每天）

## 五、上架風險初篩（2026-11 查）

| 風險 | 狀況 | 這個 app 怎麼過 |
|---|---|---|
| **4.3(b) 飽和類別** | 習慣追蹤是飽和類別；2026 年 6 月 Apple 加嚴低品質 app 的條文，AI 寫的習慣追蹤器被 4.2／4.3 退件是常見情況 | 送審說明第一段就寫差異：一次只裝一個、不算連續算回來、用曲線判定畢業。截圖第一張放竹籃（畢業），不放打勾畫面 |
| **4.2 最低功能** | 只是網頁包成 app、或單一畫面工具，容易被拒 | 正式版走原生，至少要有鎖定畫面控制項或小工具這類原生整合 |
| **健康宣稱** | 1.4.1 對健康效果宣稱很嚴 | 不宣稱任何健康、心理效果；描述只寫「幫你記錄開始」「幫你看習慣有沒有長好」 |
| **付費** | 4-3 再定；免費版必須能完整做核心動作 | — |
